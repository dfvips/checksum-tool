# CheckSumTool · 文件校验工具

跨平台（Windows / macOS / Linux）的校验文件生成、校验与合并工具，基于 **.NET 10 + Avalonia UI**。
支持 CRC64 / MD5 / SHA-1 / SHA-2 / SHA-3 / CRC-32 共 10 种算法 11 种扩展名。
